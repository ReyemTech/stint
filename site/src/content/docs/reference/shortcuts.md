## Main window

| Shortcut | Action |
|---|---|
| `⌘ ,` | Open Settings |
| `⌘ 1` | Switch to Today |
| `⌘ 2` | Switch to Settings |
| `⌘ 3` | Switch to About |
| `⌘ W` | Close main window (returns to menu-bar-only mode) |
| `⌘ Q` | Quit Stint |
| `⌘ H` | Hide window |
| `⌘ M` | Minimize window |

The number shortcuts (`⌘1` / `⌘2` / `⌘3`) only work when the main window
is focused. They don't activate from the popover or the menu bar.

## Popover

| Shortcut | Action |
|---|---|
| `Esc` | Dismiss popover |
| `Enter` | Start timer (when description field has focus and is non-empty) |
| `Tab` | Move between description, project picker, billable toggle, Start button |

## Menu bar

The Stint app menu (top of screen when the main window is focused) includes:

- **About Stint**
- **Check for Updates…** — opens main window at Settings → Updates and auto-runs a check
- **Settings…** — `⌘,`
- Standard macOS items: Services, Hide, Hide Others, Show All, Quit

## Tray (menu-bar icon)

Right-clicking the menu-bar icon shows:

- **Open Stint** — opens the main window
- **Sync now** — forces an immediate sync queue drain
- **About Stint** — opens main window at About
- **Check for Updates…** — same as the app menu item
- **Quit**

Left-clicking the tray icon toggles the popover (which has its own footer
with **Open Stint →**, ⚙ (Settings), and **Solidtime ↗** quick links).
